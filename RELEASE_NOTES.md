# ValueScale v1.2.2

Initial GitHub release of ValueScale, an always-on-top projection window for
artists to inspect the values and saturation of an application window.

## Features

- Capture a selected application window and optionally select a smaller area.
- View the capture in color or grayscale, with optional posterization, gray-value,
  brightness, and contrast controls.
- Highlight dark and light values with adjustable warning thresholds.
- Visualize saturation with the saturation warning overlay.
- Move and resize the frameless projection window; settings persist between launches.

## Getting started

Download `ValueScale_1.2.2.exe` and run it on Windows 10 or later (x64). Select
an application window to capture, then hover over the projection to reveal its
controls. No separate installation is required.

The projection does not alter the source artwork. Only application windows can
be captured; full-display capture is not available.
