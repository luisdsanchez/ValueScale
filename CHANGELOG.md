# Changelog

## 1.2.2 - Initial GitHub release

- Always-on-top projection of a selected application window or capture area.
- Color and grayscale views, optional posterization, and image adjustments.
- Adjustable dark and light value warnings and a saturation warning overlay.
- Movable, resizable projection and persistent settings.

This is an overview of the initial GitHub release, not a list of changes from
version 1.2.1.
